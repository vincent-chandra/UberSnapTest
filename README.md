# UberSnapTest

Hi my name is Vincent, this is my simple project using Computer Visualization open source (OpenCV) framework, the purpose of this project is I want to try learning openCV to edit an image and also to take a mini challenge from Uber Snap

inside the project the user can upload an image from their gallery, and change the slider value to change the image temperature either to be cooler or warmer.

The user also can save the image to their gallery
